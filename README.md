# Домашнее задание по курсу «Объектно-ориентированное программирование на Python»

Программа реализует систему управления процессом обучения (LMS), моделирующую взаимодействие студентов, лекторов и проверяющих (экспертов).

## 🚀 Функционал и особенности реализации

*   **Иерархия классов:** Реализовано наследование классов `Lecturer` (Лекторы) и `Reviewer` (Проверяющие) от базового класса `Mentor` (Преподаватели).
*   **Инкапсуляция и роли:**
    *   Выставлять оценки студентам за домашние задания могут только проверяющие (`Reviewer`).
    *   Оценивать лекции могут только студенты (`Student`).
*   **Использование `@property`:** Подсчет средней оценки у студентов и лекторов реализован через свойства (вычисляемые атрибуты), что предотвращает случайную перезапись данных извне и защищает их (read-only).
*   **Полиморфизм:** Перегружен магический метод `__str__` для всех типов пользователей для красивого и информативного вывода данных.
*   **Магические методы сравнения:** Реализована возможность сравнивать студентов между собой, а также лекторов между собой по их среднему баллу с помощью операторов сравнения (`>`, `<`, `>=`, `<=`, `==`, `!=`).
*   **Аналитика:** Добавлены глобальные функции для расчета среднего балла по конкретному курсу среди всех студентов или лекторов.

## 🛠 Требования

*   Python версии **3.8** или выше.
*   IDE (рекомендуется **GigaIDE** или **PyCharm Community Edition**).
*   Установленный **Git** для отправки работы.

## 💻 Инструкция по запуску

1. Склонируйте репозиторий или скачайте файл с кодом.
2. Откройте проект в вашей IDE.
3. Запустите файл (например, `main.py`):
   ```bash
   python main.py
   ```

## 📊 Пример вывода программы

При запуске блока тестирования вы увидите структурированную информацию по задачам:
* Проверку корректности наследования (True/False).
* Логику работы методов валидации оценок (None при успехе, Ошибка при неверных вводных).
* Данные по каждому пользователю (Имя, Фамилия, Курсы, Средний балл).
* Результаты сравнения успеваемости преподавателей и студентов.
* Финальный расчет средних показателей по выбранным дисциплинам.
